# Трекер задач

Простое однопользовательское веб-приложение для управления списком задач. Проект разработан как элемент портфолио для демонстрации навыков веб-разработки на Python.

## **ВАЖНО ДЛЯ ПРОВЕРЯЮЩИХ:** 
Пожалуйста, для оценки проекта **запустите его локально** (инструкция ниже). Демо-версия на Layero (бесплатный тариф) может работать нестабильно, долго загружаться из-за "холодного старта" (serverless) и сбрасывать данные при перезапуске контейнера (так как SQLite хранится в эфемерной файловой системе). **Локальный запуск гарантирует 100% стабильную работу и сохранение данных.** В продакшене для таких задач используется PostgreSQL.

## Функционал
-  **CRUD-операции:** Создание, чтение, редактирование и удаление задач.
-  **Управление статусом:** Отметка задач как выполненных.
-  **Фильтрация:** Просмотр всех задач, только активных или только выполненных.
-  **Адаптивный интерфейс:** Благодаря Bootstrap 5 приложение обладает адаптивностью.
-  **Сохранение задач:** Задачи не удаляются при обновлении страницы, т. к. хранятся в базе данных.

## Стек технологий
- **Backend:** Python 3, Flask
- **DB:** SQLite (Flask-SQLAlchemy)
- **Frontend:** HTML5, Jinja2, Bootstrap 5
- **Deploy:** Layero

## Как запустить локально

1. Клонируйте репозиторий:
```bash
git clone https://github.com/certainlyPeterK/task_tracker.git
cd task_tracker
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv .venv
```
Для Windows:
```bash
.venv\Scripts\activate
```
Для macOS/Linux:
```bash
source .venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Запустите приложение:
```bash
python main.py
```
Приложение будет доступно по адресу `http://127.0.0.1:5000`.
